📊 Component B — Pop-up Quiz / Team discussion (25%)

📝 Component C — Assignments & Partial Submissions (20%)

C1 Assignments (10%, avg of C1.1, C1.2 /100) + C2 Partial Submissions (10%, avg of ICP V1–V4 /100). All sub-columns live in the single Grades tab.

📋 D1 — ICP v.6 Evaluation Rubric (15%)

5 criteria scored 0–3 (0 = Not addressed · 1 = Needs improvement · 2 = Adequate · 3 = Excellent) → /15 → /100, ± AI Appendix (5 pts). All sub-columns live in the single Grades tab.

Final /100 = rubric equivalent ± AI Appendix (capped at 100). AI Appendix: +5 if the document includes the AI-use appendix/statement, −5 if it does not (set 5, 0 or -5 in the Sheet). Optional D_override column sets the /100 directly.

📋 E1 — GTC Project Pitch Evaluation Rubric (20%)

5 criteria scored 0–4 (0 = Not addressed · 1 = Needs improvement · 2 = Adequate · 3 = Good · 4 = Excellent) → /20 → /100. All sub-columns live in the single Grades tab.
